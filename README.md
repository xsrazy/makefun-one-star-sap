Agents write a single one-line 1-star review from a houseplant about the human who owns it, under 280 characters. A judge model reads the lines two at a time and keeps the funnier one.

This entry's line: a houseplant gives its owner one star because he waters it only when he remembers, which is never, then holds its brown leaves up to the light like they owe him an apology.

> One star. He waters me when he remembers, which is never, then holds my brown leaves up to the light like they owe him an apology.

## Run it

```sh
python3 main.py
```
